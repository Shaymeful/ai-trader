# AI Co-Pilot Advisory Layer

**Status**: Implementation Complete ✅
**Branch**: `feature/ai-copilot-core-and-ui`
**Version**: 1.0.0

## Overview

The AI Co-Pilot is an **advisory-only** layer that adds LLM-powered insights to your trading decisions without changing the default trading behavior. All features are **OFF by default** and require explicit opt-in.

### Key Features

1. **Trade Rationale** - AI-generated rationale for trading candidates
2. **Daily Journal** - End-of-day markdown summary of trading activity
3. **Strategy Critique** - Self-critique with recommendations for improvement

### Safety Principles

- ✅ **Default OFF** - Must explicitly enable in config
- ✅ **Never blocks loop** - All LLM failures are graceful (skip and continue)
- ✅ **Advisory-only** - Does not affect trades unless `influence_decisions: true`
- ✅ **Budget gates** - Max LLM calls per run prevents runaway costs
- ✅ **Backward compatible** - Existing code unaffected
- ✅ **Runtime overrides** - UI can toggle features without restart

## Quick Start

### 1. Enable in Config

Edit `config/config.yaml`:

```yaml
ai_copilot:
  enabled: true  # Master switch (default: false)
  influence_decisions: false  # CRITICAL: Keep false for advisory-only
  model: "gpt-4o-mini"  # Cost-effective model

  # Budget gates (safety limits)
  max_calls_per_run: 3  # Max LLM calls per loop iteration
  max_output_tokens: 350  # Token limit per response
  timeout_s: 20  # Request timeout

  # Features (toggle independently)
  trade_rationale:
    enabled: true

  daily_journal:
    enabled: true

  strategy_critique:
    enabled: true
```

### 2. Environment Variable Override

Control AI Co-Pilot globally via environment variable (overrides YAML):

```bash
# Force enable
export AI_COPILOT_ENABLED=1

# Force disable
export AI_COPILOT_ENABLED=0

# Dry-run mode (no file writes, only logs)
export AI_COPILOT_DRY_RUN=1
```

### 3. Start Trading

Run your bot as usual. AI Co-Pilot will:
- Generate rationale for top candidates (respecting budget)
- Create daily journal at end of day
- Write strategy critique to memory file

## Features

### 1. Trade Rationale

**Purpose**: Explain why a candidate is actionable right now

**Output**: Added to candidate enrichment data
- `rationale`: 2-3 sentence explanation
- `confidence`: 0-100 AI confidence score
- `risk_factors`: List of 1-3 key risks

**Example**:
```json
{
  "candidate_id": "news-AAPL-2024-01-27",
  "rationale": "Strong technical momentum with earnings catalyst. Price broke above resistance with heavy volume, confirming bullish sentiment. Sector rotation into tech supports near-term upside.",
  "confidence": 85,
  "risk_factors": [
    "Market volatility from Fed minutes",
    "Sector rotation risk if rates spike",
    "Overbought RSI suggests pullback risk"
  ]
}
```

**Budget**: ~1-3 LLM calls per run (top candidates only)

**Cost**: ~$0.001-0.003 per run

---

### 2. Daily Journal

**Purpose**: End-of-day markdown summary of trading activity

**Output**: `logs/journal/YYYY-MM-DD.md`

**Includes**:
- Summary paragraph (2-3 sentences)
- Key highlights (3-5 bullets)
- Performance analysis (P&L, win rate, etc.)
- Lessons learned (1-3 observations)
- Outlook for tomorrow

**Example**:
```markdown
# Trading Journal - 2024-01-27

**Date:** 2024-01-27
**Generated by:** AI Co-Pilot

---

## Summary

Solid day with 3 trades executed. Opened positions in AAPL and MSFT on tech sector strength. Closed GOOGL position profitably after hitting target. Overall P&L +$250 with 2/3 winners.

## Highlights

- Strong tech momentum continues - AAPL up 2.5% on volume
- Profitable GOOGL exit captured +$150 on swing trade
- MSFT entry timed well near support level
- Risk management kept losses small on one losing trade

## Performance

### Metrics
- **Realized P&L:** $250.00
- **Unrealized P&L:** -$25.00
- **Total Trades:** 3
- **Win Rate:** 66.7%

Performance was strong today with 2/3 trades profitable...

## Lessons Learned

- Waiting for pullback on MSFT entry would have improved R/R
- Exit discipline on GOOGL worked well - took profits at target
- Need to watch sector rotation signals more closely

## Outlook

Tech sector showing strength into week-end. Watch for Fed minutes impact on Monday. AAPL and MSFT positions look solid for continuation.

---

*Generated on 2024-01-27 by AI Co-Pilot*
```

**Budget**: 1 LLM call per day (idempotent - only generates once)

**Cost**: ~$0.002-0.004 per day

### 3. Strategy Critique

**Purpose**: Self-critique with recommendations for improvement

**Output**: `data/strategy_memory.jsonl` (append-only)

**Includes**:
- `critique`: Honest 2-3 sentence assessment
- `recommendations`: 2-4 actionable improvements
- `confidence`: 0-100 confidence in current approach
- `strengths`: 1-3 things working well
- `weaknesses`: 1-3 things needing work

**Example**:
```json
{
  "date": "2024-01-27",
  "timestamp": "2024-01-27T16:00:00Z",
  "critique": "Win rate is decent at 67% but holding losers too long. Exit discipline needs improvement - best trade was +$150 but worst was -$80, showing asymmetric risk management issues.",
  "recommendations": [
    "Tighten stop losses to 2% max per position",
    "Take profits earlier when targets hit (don't get greedy)",
    "Add technical confirmation before entries",
    "Review trade journal weekly to spot patterns"
  ],
  "confidence": 72,
  "strengths": [
    "Good entry timing on tech sector momentum",
    "Proper position sizing within risk limits",
    "Profitable GOOGL exit showed discipline"
  ],
  "weaknesses": [
    "Holding losing positions too long",
    "Not taking profits at target levels consistently",
    "Need better pre-trade planning"
  ],
  "performance": {
    "total_trades": 3,
    "win_rate": 0.667,
    "realized_pnl": 250.0,
    "avg_hold_time_hours": 4.5
  }
}
```

**Budget**: 1 LLM call per day (idempotent - only generates once)

**Cost**: ~$0.002-0.004 per day

## Configuration Reference

### Config File (`config/config.yaml`)

```yaml
ai_copilot:
  # Master switch
  enabled: false  # Default OFF for safety

  # CRITICAL SAFETY FLAG
  # When false (default), AI outputs are purely advisory
  # When true, AI can influence trading decisions
  influence_decisions: false

  # Model configuration
  model: "gpt-4o-mini"  # Recommended: cost-effective

  # Budget gates (safety limits)
  max_calls_per_run: 3      # Max LLM calls per loop iteration
  max_output_tokens: 350    # Token limit per response
  timeout_s: 20             # Request timeout in seconds

  # Feature flags (toggle independently)
  trade_rationale:
    enabled: true

  daily_journal:
    enabled: true

  strategy_critique:
    enabled: true
```

**Precedence**: `ENV VAR > UI Runtime Overrides > YAML > Defaults`

## Troubleshooting

### AI Co-Pilot Not Running

**Check 1: Is it enabled?**
```bash
# Check config
grep -A 2 "ai_copilot:" config/config.yaml

# Check env var
echo $AI_COPILOT_ENABLED
```

**Check 2: Budget exhausted?**
```bash
cat logs/ai_copilot/latest_status.json | jq '.budget'
```

**Check 3: Check logs**
```bash
grep "ai-trader.copilot" logs/loop/loop_*.log
```

### LLM Calls Failing

**Symptom**: Status shows `health: "degraded"` or low success rates

**Possible Causes**:
1. OpenAI API key not set or invalid
2. Rate limiting (unlikely with our usage)
3. Network issues
4. Model unavailable

**Check**:
```bash
# Verify API key
echo $OPENAI_API_KEY | wc -c  # Should be ~50+ chars

# Check errors in logs
grep "ai-trader.copilot.*error" logs/loop/loop_*.log
```

### Budget Too Low

**Symptom**: Features not generating outputs, budget exhausted early

**Solution**: Increase `max_calls_per_run` in config:
```yaml
ai_copilot:
  max_calls_per_run: 5  # Increased from 3
```

**Cost Impact**: +$0.003-0.006 per day

### Dry-Run Mode Stuck

**Symptom**: AI Co-Pilot enabled but no files generated

**Check**:
```bash
echo $AI_COPILOT_DRY_RUN  # Should be unset or "0"
```

**Fix**:
```bash
unset AI_COPILOT_DRY_RUN
```

## Architecture

### Components

```
src/app/llm_advisors/
├── __init__.py               # Exports
├── client.py                 # CoPilotClient (budget-gated)
├── trade_rationale.py        # Per-candidate analysis
├── daily_journal.py          # End-of-day markdown
├── strategy_critique.py      # End-of-day critique
└── status.py                 # Status snapshots
```

### Integration Points

1. **Runner Loop** (`src/app/runner.py`)
   - Initialize CoPilotClient at start
   - Call trade_rationale during candidate evaluation
   - Call daily_journal at end of day
   - Call strategy_critique at end of day
   - Write status snapshot after each run

2. **UI API** (`src/ui_api/app.py`)
   - GET routes for monitoring
   - POST routes for runtime controls

3. **Config** (`src/app/config.py`)
   - Pydantic fields for ai_copilot settings
   - Environment variable override logic

### Data Flow

```
Runner Loop Start
  ↓
Initialize CoPilotClient
  ↓
Reset Budget (call_count = 0)
  ↓
[Candidate Evaluation]
  ↓
  ├→ generate_trade_rationale() → advisory metadata
  │
[End of Run]
  ↓
  ├→ generate_daily_journal() → logs/journal/YYYY-MM-DD.md
  ├→ generate_strategy_critique() → data/strategy_memory.jsonl
  └→ write_status_snapshot() → logs/ai_copilot/latest_status.json
  ↓
Runner Loop End
```

## FAQ

**Q: Will this change my trading decisions?**
A: No, unless you set `influence_decisions: true` (not recommended).

**Q: What if OpenAI is down?**
A: Loop continues normally. AI Co-Pilot gracefully degrades (logs error, returns None).

**Q: Can I use Anthropic instead of OpenAI?**
A: Currently OpenAI only, but easy to extend (see `src/app/llm/factory.py`).

**Q: How much does this cost?**
A: ~$0.009/day (~$3.30/year) with default settings.

**Q: Can I disable individual features?**
A: Yes, via config or UI endpoints.

**Q: Does this work in paper trading mode?**
A: Yes, works in all modes (mock, paper, dry-run, live).

**Q: Can I review AI outputs before they're used?**
A: Yes, all outputs are written to files for review. With `influence_decisions: false`, they're purely advisory.
