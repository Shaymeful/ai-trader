HOW IT WORKS:
==========================================

1. UI Changes Interval:

   - Before each save, runner reloads loop_interval_seconds from file
   - Ensures UI changes are not overwritten

3. Hot-Reload Applies Changes:
   - Before sleeping, runner checks if interval changed
   - Updates sleep duration for next iteration

USAGE:
==========================================

1. Open dashboard: http://localhost:8000

2. Find "Loop Status" section

3. Click "Edit" button next to interval

4. Enter new interval in MINUTES (e.g., 10 for 10 minutes)

5. Click "Save"

6. Wait for current sleep to complete

7. Next iteration will use new interval

IMPORTANT:
==========================================
- Changes take effect on NEXT iteration (after current sleep)
- If you change from 5min to 10min, current 5min sleep completes first
- Then next iteration uses 10min interval going forward

MONITORING:
==========================================
- Dashboard shows countdown with current interval
- state/runtime.json shows loop_interval_seconds
- logs/loop_status.log shows iteration timestamps
